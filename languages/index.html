    Languages¶

    --language takes any row of this table either way: the tag (--language zh-hant) or the name (--language "traditional chinese", case-insensitive). The tag is the mechanical half — stamped on the inserted markup and dc:language, recorded in the translation metadata record, and it names the structured-output reply field (zh_hant_translation). The name is the prose half: what the model is actually asked for.

    For a language this table misses, pass both halves yourself as TAG:NAME, split on the first colon — for example --language "ain:Ainu". The tag then drives the stamps and field names exactly as if it were listed here; the name goes to the model. A free-typed name matching nothing still runs — the run prints one Note: line saying nothing will be stamped on the output.

    The source language is never part of --language; --source_lang states it when auto-detection isn't enough.
